## 運用保守費（月額）

本番公開（Phase 2 完了）以降、継続的に発生する保守運用作業に対する月額費用です。


| 項目   | 内容                   |
| ---- | -------------------- |
| 月額費用 | **30,000円**（税別）      |
| 開始時期 | 本番公開後（Phase 2 完了日）から |
| 契約単位 | 月単位（都度更新）            |


**対象作業**:


| 作業内容               | 概要                                   |
| ------------------ | ------------------------------------ |
| エラーモニタリング          | CloudWatch / Sentry 等でのエラー・異常検知と初動対応 |
| ライブラリ・セキュリティアップデート | フレームワーク・パッケージの脆弱性対応・定期アップデート         |
| ランタイムバージョン管理       | Node.js 等のランタイム EOL 対応               |
| 軽微な障害・設定変更対応       | 軽微なバグ修正・環境設定変更（1件あたり1〜2時間程度）         |
| 月次稼働レポート           | 稼働状況・エラー件数・対応内容の月次報告                 |


> 機能追加・大規模改修は対象外。発生時は別途お見積もりします。
