# 味和商店 マニュアル閲覧システム 概要

**作成日**: 2026-06-06
**作成者**: 喜多亮介

---

## このシステムで実現すること

**「いつでも・どこでも・誰でも、マニュアルを見ながら仕事ができる環境」** を作ります。

現在、紙やLINEなどで共有しているマニュアルを一元管理し、スタッフが必要なときに必要な情報をすぐ取り出せるようになります。味和商店さんが開発者に頼らずコンテンツを更新できるため、マニュアルを常に最新の状態に保てます。

---

## 完成後にできること

### スタッフ（現場）視点


| できること             | 説明                               |
| ----------------- | -------------------------------- |
| 動画マニュアルを見ながら作業できる | スマホ・PCでYouTube動画を視聴しながら業務を確認できます |
| テキストで工程を確認できる     | 手順を文章・画像で確認できます                  |
| 自分のレベルに合った内容を探せる  | 難易度フィルタで「初級・中級・上級」などに絞り込んで閲覧できます |
| 知りたい情報をすぐ検索できる    | キーワードを入力するだけで関連マニュアルが出てきます       |
| PDFで印刷できる         | 手元に置いておきたいときは印刷用PDFをダウンロードできます   |
| 全画面で動画を視聴できる      | 作業しながら大きな画面で動画を確認できます            |
| 連絡事項を確認できる        | 管理者からのお知らせを見逃さず確認できます            |


### 管理者（味和商店）視点


| できること                | 説明                                   |
| -------------------- | ------------------------------------ |
| マニュアルを自分で登録・更新できる    | 開発者に頼まずに、いつでも内容を追加・変更・削除できます         |
| カテゴリ・難易度を自由に整理できる    | 業務の変化に合わせてカテゴリ構成を変えられます              |
| アカウントを自分で発行・管理できる    | 新しい店舗・スタッフのアカウント発行やアカウント停止を自分で対応できます |
| 店舗・ロールに応じた公開範囲を設定できる | 「店長アカウントだけに見せる」など、閲覧権限を設定できます        |
| 連絡事項を投稿できる           | お知らせや重要事項を全スタッフまたは特定店舗に向けて発信できます     |
| 工程テキストに画像を添付できる      | 文章だけでなく、写真や図を使ってわかりやすいマニュアルを作れます     |

## 実装スケジュール

### Phase 1：まず「見られる」状態を作る（〜2026年X月）

> **目標：スタッフが動画・テキストマニュアルを本番環境で閲覧できる**

- トップ画面・カテゴリ一覧・マニュアル一覧・詳細ページの表示
- YouTube動画の埋め込み再生
- 本番環境の構築・公開

---

### Phase 2：「使いやすくする」（〜2026年X月）

> **目標：現場で毎日使ってもらえる使い心地に仕上げる**

- 全画面動画再生
- キーワード検索
- 難易度別フィルタ
- PDFダウンロード

---

### Phase 3：「味和商店さんが自分で管理できる」（〜2026年X月）

> **目標：開発者なしでコンテンツを更新できる体制を作る**

- 管理画面からマニュアル・カテゴリの登録・編集・削除
- 難易度ラベルの管理

---

### Phase 4：「誰に見せるか・誰が使うかを管理できる」（〜2026年X月）

> **目標：セキュリティを担保しつつ、店舗・ロールに応じた運用ができる**

- ログイン機能（スタッフ・管理者）
- アカウント発行・停止・編集
- 店舗・ロール別の閲覧権限設定
- システム管理者とコンテンツ管理者の権限分離

---

### Phase 5：「お知らせ・連絡事項の発信」

> **目標：LINEや口頭に頼らず、システム内でお知らせを管理する**

- 連絡事項の投稿・編集・削除
- 重要度設定・検索
- 特定店舗への公開範囲設定

---

### Phase 6：「画像で伝わるマニュアル」

> **目標：文章だけでなく、写真・画像でわかりやすいマニュアルを実現する**

- 工程テキストへの画像添付・管理
- 画像付き工程テキストの閲覧

---

## 推しポイント

### 月額費用ゼロで運用できる

継続的な月額保守費用は発生しません。サーバーの実費のみで運営でき、毎月3,000〜5,000円程度が目安です。

### 開発者なしで運用が続けられる

管理画面からコンテンツを自由に更新できるため、新しいメニューや業務フローが変わっても、味和商店さん自身でマニュアルを最新の状態に保てます。引き渡し時にシステムマニュアルも納品するので、操作に迷いません。

### 段階的にシステムを開発

まず「見られる」状態から始めて、使いながら機能を追加していきます。最初から全機能を一気に作らないので、出来上がった機能から現場で使用することができます。

### 将来の拡張も対応可能

多言語対応・新機能の追加など、必要になったタイミングで都度ご相談いただけます。（開発完了後2ヶ月は軽微な修正対応を無料対応いたします。）
