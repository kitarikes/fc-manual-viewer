作業内容概要
エラーモニタリング CloudWatch / Sentry 等でのエラー・異常検知と初動対応

機能追加・大規模改修は対象外です。発生時は別途お見積もりします。

インフラ費用（参考・AWS）

3,000〜5,000円／月
AWS 費用はクライアント（吉良さん）が直接 AWS に支払うため、上記見積もりには含まれません。
実費は利用状況・構成によって変動します。初期セットアップ（環境構築・CI/CD 整備）は Phase 2 の開発費に含みます。
AWS アカウントの開設・請求管理はクライアント側でご対応いただきます。
